## 🎮 Игровые режимы

| Режим | Описание |
|---|---|
| 🤖 Bot | Три уровня сложности |
| 👥 Local | Игра вдвоём |
| 🌐 P2P | Игра с другом онлайн |

## ✨ Возможности

- 👑 Дамки
- ⚔️ Обязательное взятие
- 🔥 Серии взятий
- ↶ Отмена ходов
- 📱 Поддержка телефонов
- 💻 Поддержка компьютеров
- 🌍 Мультиплеер через WebRTC

## 🕹️ Как играть

1. Открой игру.
2. Выбери режим.
3. Начни партию.
4. Победи соперника!

## 🌐 Онлайн-игра

Для подключения к другу:
1. Создай приглашение.
2. Отправь код другу.
3. Получи ответный код.
4. Подключись и играй!
